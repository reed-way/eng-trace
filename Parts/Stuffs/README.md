# Parts / Stuffs

句子中事物主体

## `...`
> - 泛指所有的
> - 抽象的
> - 群体的

## a/an `...`
> - 首次提到
> - 随便一个

## one `...`
> - 前文群体中特定的一个
> - 强调数量

## the `...`
> - 明确的、已知的
> - 前文已提到
> - 维一的
> - 客观环境
> - 最高比较级

## all `...s`
> - 泛指的、整类的

## all of `...s`
> - 特定的、特指的
> - 我们、他/它们、你们 (`...` all) 

## (every`...`) / (all `A do`)
> 绝对程度上的全部、所有
