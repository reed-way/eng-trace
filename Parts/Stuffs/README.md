# Parts / Stuffs

句子中事物主体

## `...`
> - 泛指所有的
> - 抽象的
> - 群体的(复数、不可数)
> - 专有词（地名、人名、学科、语言、运动、餐名）

## a/an `...`
> - 首次提到
> - 随便一个
> - 可数

## one `...`
> - 前文群体中特定的一个
> - 强调数量
> - 同等的另一个

## the `...`
> - 明确的、已知的
> - 前文已提到
> - 唯一的
> - 客观环境
> - 突出的（最高级）

## all `...s`
> - 泛指的、整类的

## all of `...s`
> - 特定的、特指的
> - 我们、他/它们、你们 (`...` all) 

## (every`...`) / (all `A do`)
> 绝对程度上的全部、所有
