# eng-trace

## Intro
这是一个结构化项目，目的是帮助中文母语者归纳英文表达的逻辑脉络。它的主要构想是利用项目的目录结构建立对应思维路径来指导创建正确的英语句子。

## Idea
这个想法类似于英语学习的笔记，它真正的作用不像是词典类的工具，而是试图通过这种方式帮助学习者加深记忆或者是快速建立起有效的造句框架。本质上是探寻一种新的可行方式来掌握英语。特别是对中文用户来说，它以中文逻辑的思考度角度出发，这是更友好的一面。

## Vision
在初期，此项目只能从个人的学习笔记开始，基于经验逐步成长。
如果可能，希望项目未来可以得到更多人的贡献，扩展并壮大，进而建立起完善、全面的体系来帮助更多有需要的人。
