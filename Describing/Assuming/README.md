# Describing / Assuming

假定一个前提条件后，会发生什么结果
> be 统一用 were, was 属于非正式（只适用口语）

## if ... `do` ..., ... will `do` ...
> 客观事件，常理，条件与结果是强关系

## if ... `did` ..., ... would `do` ...
> 目前未发生的事件

## if ... had `done`, ... would have `done`
> 对已经发生的事件与结果重新假设

## if ... had `done`, ... would `do` ...
> 如果过去事件不同，现在的结果也不同
