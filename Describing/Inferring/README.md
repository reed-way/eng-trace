# Describing / Inferring

其于当前信息来描述（猜测）一个可能的事实

## ... [-probability](/Parts/Probability/) be
> 一个事实的可能性

## ... [-probability](/Parts/Probability/) have `done`
> 已经如何了的可能性, 其中：
> - could have done 另可表达：本来可以做
> - might have done 另可表达：本有机会做

## ... [-probability](/Parts/Probability/) have been `doing`
> 一直在如何的可能性
